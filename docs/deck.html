Unreal Engine 5.8 sample

Build a Bachelor

Drop characters into a level, press Play, and they talk to each other and to you. Their emotions change as they go, and every change is an event you can hook.

No Blueprint graph to wire. One component on an actor, one API key in Project Settings.

Install

Download, open, Play

No git and no Visual Studio: get BuildABachelor-UE5.8.zip from github.com/storyliving/fermata-unreal-template, unzip it, double-click BuildABachelor.uproject in UE 5.8 and press Play.

To change the plugin itself (maintainers):

git clone https://github.com/storyliving/build-a-bachelor.git
cd build-a-bachelor
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
  1. Unzip the character pack (Releases) into BuildABachelor/Content/.
  2. Open BuildABachelor.uproject in UE 5.8 and click Yes to build the plugin.
  3. The level BAB_Villa opens by default.
API key

Project Settings > Plugins > Fermata

It already works: the project ships with a shared public key. To use your own, paste it into Fermata API Key.

It is saved to Saved/FermataEvent/event-key.txt on your machine, never to Config/, so it cannot be committed. You can also press K in game, pass -FermataEventKey=, or set FERMATA_EVENT_KEY.

The shared key is rate limited and will be switched off after the event; when it is, the characters go quiet.

Make your own character

Write who they are. Press Play.

1 · Duplicate the templateBP_MyCharacter_Template: a bible slot, a mesh slot, and On Emotion Changed, On Line Spoken and On Aware Of Object already stubbed with notes.
2 · Edit the Character BibleDuplicate DA_Bible_Example and rewrite it: Who They Are (the personality), Life So Far, Wants, Fears, Secret, How They Talk, Example Lines, Relationships, Quirks, Voice From.
3 · Set the Scene DescriptionThe level's Fermata Scene actor: setting, time of day, mood, what is going on, and who the player is. Every character hears it.

Change one line in the bible, press Play, and the character answers differently. Specifics beat adjectives: "failed his own road test twice" works, "insecure" does not. Guide: Docs/CHARACTER_BIBLE.md.

Custom behaviour

Bind an event, do anything

Select the Fermata Character component, then under Events click +:

EventUse it to
OnEmotionChangedplay a montage, swap a material, fire VFX
OnLineSpoken / OnLineHeardgesture, react, cut the camera
OnConversationStarted / Endedwalk over, sit down, return to a mark
OnAwareOfObjectlook at it, pick it up
OnCharacterSwappedrefresh UI or outfit

Room-wide: Get Fermata Director > OnRoomLine, HoldRoom, SetDirectorCamera.

Aware Objects

Drag it in, name it, done

  1. Drag Fermata Aware Object (or BP_AwareObject) into the level and set its mesh.
  2. Object Name: "The Last Rose". Description: "Whoever holds it at the end of the night stays."
  3. Perception Radius: how close a character must be to notice it.

Characters in range fire OnAwareOfObject and start mentioning it. Stand a character next to it and the room is told they have it. Or add a Fermata Aware component to any actor you already have.

What lives where

Thin plugin, smart backend

The plugin carries words, emotions and audio, and drives faces, voices and lights.

Who the characters are, who speaks next, what they remember, their voices and every provider credential stay on Fermata HQ, behind your event key. The plugin ships compiled only, and every package passes a clean-room scan: one shared public key, no source, no prompts.

Not in this build: a guest's own 3D model at runtime (U brings their mind, bio and voice into the body you pick; plan: Interchange in the editor, glTFRuntime for packaged games), a Willa MetaHuman, and a sample on the jaw or blendshape tiers (Toucantino is next).
